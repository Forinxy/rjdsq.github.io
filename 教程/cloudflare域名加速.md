### 模板一：Cloudflare Pages 优选加速版
**适用场景**：通过 Cloudflare Pages 部署的静态网站、React/Vue 项目等。
| 步骤 | 操作模块 | 具体设置内容 |
|---|---|---|
| **1. 总闸口** | **DNS -> 记录** | 添加 CNAME 记录：名称 ip，目标 www.pages.dev，**开启小黄云**。 |
| **2. 设置回源** | **SSL/TLS -> 自定义主机名** | 在 **回退源 (Fallback Origin)** 处填入：ip.baidu.com。 |
| **3. 绑定域名** | **SSL/TLS -> 自定义主机名** | 点击 **添加自定义主机名**，填入：www.baidu.com，等待状态变绿。 |
| **4. 伪装身份** | **规则 -> 源站规则** | 创建规则：匹配 主机名 等于 www.baidu.com；
操作：主机标头 重写为 www.pages.dev。 |
| **5. 国内解析** | **DNS -> 记录** | 添加 CNAME 记录：名称 www，目标 cf.877774.xyz，**关闭小黄云**。 |
### 模板二：Cloudflare Workers 优选加速版
**适用场景**：通过 Workers 部署的 API、代理、动态网页等。
| 步骤 | 操作模块 | 具体设置内容 |
|---|---|---|
| **1. 总闸口** | **DNS -> 记录** | 添加 CNAME 记录：名称 ip，目标 www.user.workers.dev，**开启小黄云**。 |
| **2. 设置回源** | **SSL/TLS -> 自定义主机名** | 在 **回退源 (Fallback Origin)** 处填入：ip.baidu.com。 |
| **3. 绑定域名** | **SSL/TLS -> 自定义主机名** | 点击 **添加自定义主机名**，填入：www.baidu.com，等待状态变绿。 |
| **4. 内部路由** | **Workers -> 触发器** | 进入对应 Worker 项目，在 **路由 (Routes)** 处添加：www.baidu.com/*。 |
| **5. 国内解析** | **DNS -> 记录** | 添加 CNAME 记录：名称 www，目标 cf.877774.xyz，**关闭小黄云**。 |
### 💡 核心避坑指南（永久生效）：
 1. **回退源唯一性**：即便你以后有 100 个加速站点，第 1 步和第 2 步在每个根域名下**只需要做一次**。以后所有的加速站点都共用同一个 ip.baidu.com 作为入场券。
 2. **Pages vs Workers 的区别**：
   * **Pages** 必须做第 4 步的 **“源站规则 (Host 重写)”**，否则会报 404。
   * **Workers** 必须做第 4 步的 **“路由 (Routes)”**，否则请求进不到代码里。
 3. **小黄云开关**：
   * **回退源 (ip)** 记录必须**开**小黄云。
   * **加速站点 (www)** 记录必须**关**小黄云。
 4. **证书状态**：如果访问报 SSL 错误，请去“自定义主机名”里检查证书是否为 **Active (有效)**。只要状态是绿色的，优选 IP 就能正常承载 HTTPS 流量。
​⚠️ 唯一的绝对核心法则
​无论你用 CNAME、A 还是 AAAA 记录指向优选节点，代理状态（小黄云）必须保持关闭（仅 DNS / Gray Cloud）！
